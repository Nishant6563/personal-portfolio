# Nishant Dharra — Personal Portfolio

A responsive portfolio showcasing my journey as a computer science student interested in AI, machine learning and software development. Explore my projects, experience, skills and resume in one place.

## Website

**GitHub Pages website:** [nishant6563.github.io/personal-portfolio](https://nishant6563.github.io/personal-portfolio/)

## Features

- Responsive layouts for desktop and mobile.
- Three homepage color themes and animated visual elements.
- Project cards with filters and detailed descriptions.
- Resume page with a print / save as PDF option.
- Contact form with validation and email delivery through FormSubmit (email activation is required).
- Links to GitHub, LinkedIn, email, and the AI Academic Chatbot demo.

### Gold Price Prediction

## Portfolio technology

HTML5, CSS3 and JavaScript. The contact form posts to the third-party FormSubmit service, which forwards enquiries to the portfolio owner's email after activation.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser, or serve the files using a local web server.
3. Use the navigation to explore Work, About, Experience, Resume and Contact.

## Activate the contact form

After the site is published, submit one test message from the Contact page. Open the activation email from FormSubmit in the destination inbox and confirm it. Check spam if it does not arrive. Test the form again to verify delivery.

## Publish with GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Wait for the deployment to finish and check the published link shown by GitHub.
